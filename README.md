# RentKaroPune

A modern rental property listing platform for Pune, India.

## Features
- Browse owner & broker-listed rental properties across Pune
- Subscription-based listing plans (Free / Pro / Business)
- Admin dashboard with analytics, lead management, and CSV export
- WhatsApp & callback contact system
- Secure image uploads via Cloudinary
- Rate limiting, CSRF protection, and security headers

## Tech Stack
- **Framework:** Next.js 15 (App Router)
- **Database:** Firebase Firestore
- **Storage:** Cloudinary
- **Auth:** Firebase Auth
- **Deployment:** Vercel

## Getting Started
```bash
npm install
npm run dev
```
